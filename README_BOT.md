# IKK VPN — Telegram-бот

Бот: оплата подписки **звёздами Telegram (XTR)**, выдача подписки для **Happ**,
**мини-приложение** с инструкциями по устройствам и **реферальная система
(+10 дней за оплатившего друга)**.

## 1. Подготовка

1. Создайте бота у **@BotFather** → получите `BOT_TOKEN`.
2. Узнайте свой Telegram ID у **@userinfobot** (для уведомлений об оплатах) → `OWNER_ID`.
3. Telegram Stars включены у ботов по умолчанию — отдельный платёжный провайдер **не нужен**.

## 2. Установка зависимостей

```bash
pip install -r bot/requirements.txt
```

## 3. Переменные окружения

| Переменная | Зачем | Пример |
|------------|-------|--------|
| `BOT_TOKEN` | токен от @BotFather (обязательно) | `123456:ABC...` |
| `BOT_USERNAME` | юзернейм бота (для реф-ссылок) | `IKKvpnpbot` |
| `SUPPORT_BOT_USERNAME` | бот поддержки — кнопка «Поддержка» и упоминания в текстах | `IKKvpnsupport_bot` |
| `OWNER_ID` | ID владельца для уведомлений | `123456789` |
| `WEBAPP_URL` | HTTPS-адрес мини-приложения (инструкция) | `https://ваш-домен/app` |
| `OFFER_URL` | HTTPS-адрес мини-приложения оферты | `https://ваш-домен/offer-app` |
| `SUB_BASE_URL` | база подписок вашей VPN-панели | `https://panel/sub` |
| `REFERRAL_BONUS_DAYS` | дней за реферала | `10` |
| `REFERRAL_ON_TRIAL` | `1` — начислять бонус уже за триал друга (по умолчанию только за оплату) | `0` |
| `SALE_BONUS_DAYS` / `SALE_UNTIL` | акция: бонусные дни к месяцу и дата окончания (включительно) | `20` / `2026-08-03` |
| `SUB_REMIND_BEFORE_DAYS` | за сколько дней напоминать о продлении | `3` |
| `ADVOCACY_AFTER_DAYS` | через сколько дней просить порекомендовать сервис | `10` |
| `RETURN_PROMO_CODE` / `RETURN_PROMO_DAYS` | промокод для рассылки `/broadcast_lapsed` | `COMEBACK` / `5` |

### Команды владельца (рассылки)

| Команда | Кому | Про что |
|---------|------|---------|
| `/broadcast_sale` | всем | акция «+N дней к месяцу», блокируется после `SALE_UNTIL` |
| `/broadcast_promo` | всем | промокод `PROMO_CODE` с кнопкой активации |
| `/broadcast_ref` | всем | реферальная программа, ссылка у каждого своя |
| `/broadcast_nc` | активным, кто ни разу не подключался | «вы ещё не подключились» |
| `/broadcast_lapsed` | у кого подписка кончилась (не старше 180 дн.) | «возвращайтесь» + промокод |

Заблокировавшие бота помечаются в базе и из следующих рассылок исчезают —
вернутся сами, если снова напишут боту.

Windows (PowerShell), на один сеанс:
```powershell
$env:BOT_TOKEN="ваш_токен"; $env:OWNER_ID="ваш_id"; python run_bot.py
```

## 4. Запуск

```bash
python run_bot.py
```

## 5. Мини-приложение (инструкции)

Страница `/app` вашего сайта (`templates/webapp.html`) — это и есть мини-приложение.
Telegram требует **HTTPS**, поэтому:
1. Задеплойте сайт по HTTPS (домен).
2. Укажите `WEBAPP_URL=https://ваш-домен/app` — кнопка появится в боте.
3. (Опц.) В @BotFather → *Bot Settings → Menu Button → Web App* укажите тот же URL.

Локально без HTTPS Web App не откроется, но в боте есть текстовые инструкции по
каждому устройству (кнопки iOS / Android / Windows / macOS / Android TV).

## 6. Выдача VPN-ключей — панель Marzban

Бот подключён к **Marzban** ([`bot/panel.py`](bot/panel.py)): при оплате он создаёт
(или продлевает) пользователя в панели и присылает его subscription-URL для Happ.

Переменные окружения панели:

| Переменная | Зачем | Пример |
|------------|-------|--------|
| `PANEL_URL` | адрес панели Marzban | `https://panel.example.com` |
| `PANEL_USERNAME` | логин администратора (sudo) | `admin` |
| `PANEL_PASSWORD` | пароль администратора | `••••••` |
| `PANEL_INBOUNDS` | (необяз.) JSON инбаундов | `{"vless": ["VLESS TCP REALITY"]}` |
| `PANEL_PROXIES` | (необяз.) протоколы | `{"vless": {}}` |
| `PANEL_VERIFY_SSL` | `0` чтобы не проверять SSL | `1` |

**Проверьте связь с панелью** (после установки переменных):
```bash
python -m bot.panel
```
- «✅ Авторизация успешна» — всё работает, заодно покажет список инбаундов для `PANEL_INBOUNDS`.
- «⚠️ Панель НЕ настроена» — задайте переменные.
- «❌ Не удалось подключиться» — проверьте URL/логин/SSL/доступность сервера.

Если панель не настроена — бот работает в демо-режиме (платежи и подписки считаются,
но ключ присылает администратор вручную).
